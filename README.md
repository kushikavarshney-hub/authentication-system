# Authentication System

A simple authentication system built using React.

## Features

- User signup
- User login
- Store user details using localStorage
- Login validation
- Protected dashboard
- Logout functionality
- Navigation using React Router
- Form validation

## Technologies Used

- React
- JavaScript
- React Router
- CSS
- Vite

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

npm install

5. Then run:

npm run dev

6. Open the local link shown in the terminal.
